#   uv pip install --require-hashes --no-deps --only-binary :all: --torch-backend cpu -r <lock>
# (drop --torch-backend cpu on macOS). Those locks have no `openvino` package, which the OpenVINO IR
# step of export_model.py needs (--no-openvino skips it); install it next to them with
