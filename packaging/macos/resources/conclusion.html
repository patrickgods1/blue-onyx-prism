Blue Onyx Prism is installed

The service is running. The first start downloads the runtimes and model, which can take a few minutes. Open https://localhost:32169/ for the status and configuration page (the browser warns once about the service's self-signed certificate) and create the first account there with the one-time setup code this Terminal command prints:

sudo -u _blueonyx /usr/local/blue-onyx-prism/blue-onyx-prism --config /usr/local/var/blue-onyx-prism/blue_onyx_prism_config.json setup-code

Point Blue Iris at this machine, port 32168 (plain HTTP; it needs no account).

A Blue Onyx Prism icon now appears in the menu bar (and at every login). Its menu shows the service status and can start, stop or restart the service (macOS asks for an administrator password) and open the web UI. If you quit it, open Blue Onyx Prism in your Applications folder to bring it back.

Logs: /var/log/blue-onyx-prism

Uninstall

Open Uninstall Blue Onyx Prism in your Applications folder. It can keep your configuration, models, dataset, reviewed labels, training runs and logs for a later reinstall, or delete everything.
