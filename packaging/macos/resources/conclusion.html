Blue Onyx Prism is installed

The service is running. The first start downloads the runtimes and model, which can take a few minutes. Open http://127.0.0.1:32168/ for the status and configuration page, and point Blue Iris at this machine, port 32168.

Logs: /var/log/blue-onyx-prism

Uninstall

In Terminal run sudo /usr/local/blue-onyx-prism/scripts/uninstall_launchd.sh (add --purge to also delete the data, logs and the service account), then delete /usr/local/blue-onyx-prism.
