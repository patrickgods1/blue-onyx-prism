Blue Onyx Prism

Object detection for Blue Iris (CodeProject.AI-compatible API), running as a background service.

This installer puts the program in /usr/local/blue-onyx-prism, its data in /usr/local/var/blue-onyx-prism and its logs in /var/log/blue-onyx-prism, creates the hidden service account _blueonyx and starts the service at boot.

The inference runtimes (OpenVINO, ONNX Runtime) and the default model are downloaded by the service on first start, so the machine needs internet access then. An existing configuration is kept.
