Benchmark

Runs each model on each device over the chosen image sets with the production pipeline, grades accuracy and speed, and recommends a device and a confidence threshold per model. Results: {{ results_file }} · JSON: /v1/benchmark.

How grading works

Accuracy is AP@0.5, or the frame-level ROC AUC: how well a frame's top confidence separates frames with an object from frames without, which is Blue Iris's alert decision; against ground truth, or against a reference model where a dataset has none. Speed is the full request p50. Every device is checked to detect the same objects as the CPU. The recommended device of a model is its best-graded device whose detections agree with the CPU; within 5% of the best speed the configured device is kept. The same predictions are also scored at every confidence threshold (no extra inference) to find each model's best confidence threshold for the chosen objective. Speeds are per image, one at a time; the service pipelines decode, preprocessing and inference (and runs several inferences at once where the hardware profile allows), so its throughput is higher than 1000 / latency implies. The benchmark CLI writes the same results file.
