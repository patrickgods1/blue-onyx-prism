    Auto-label these frames

    Proposes boxes for the frames the filters above select: they appear here as pending auto boxes. The labelers (MM-Grounding-DINO + RF-DETR L, checked by Qwen3-VL and SigLIP 2; NVIDIA GPU or Apple silicon) mark each box accept or review. A model (any detector from your config, a model file or a downloadable one) runs on any device, CPU included (RF-DETR L on CPU takes about 1 s per frame); its boxes are review unless you pre-accept them above a score. Frames the filters leave open default to the unreviewed ones in model mode. Runs on the Training page's queue, where the progress and a self-training check are.

    Classes to look for

    The classes default to the ones your enabled models detect, within the class list and not hidden in Review; change which models detect what on the Config page (Models, Classes).

    Saves the unreviewed frames the filters select whose boxes are all auto: accept as reviewed (asks first).
    Pending auto boxes scoring below it on the unreviewed frames the filters select are rejected (kept as hard-negative evidence; a reviewer can still change them per frame). Asks first.
    Pending model and auto boxes of classes you do not want (not in the class list, or marked don't want under Classes), on the unreviewed frames the filters select, are rejected (reason other_class, kept as evidence); a class of the list under another spelling (pottedplant) is renamed instead. Asks first, then asks about reviewed frames that still hold accepted boxes of them.

    Export reviewed frames

    Writes YOLO (images/, labels/, data.yaml), COCO (annotations/), X-AnyLabeling (xanylabeling/) and a benchmark set (benchmark/, run it with benchmark --dataset dir:<folder>/benchmark). The split holds out whole cameras or days. A class filter keeps the frames with a reviewed box of those classes; their other boxes stay labelled.

    Import from X-AnyLabeling

    Reads the .json files of an exported xanylabeling folder after you edited them in X-AnyLabeling. A file counts once its image is checked there; its rectangles become the frame's boxes (boxes you deleted are kept as rejected).

    Classes applies now

    The class list of this page and of the exports (collect.classes); YOLO class ids follow this order, so append rather than reorder once you exported. Don't want hides a class from this page (pickers, shortcuts and its boxes) and rejects its pending boxes on the unreviewed frames right away, as removing a class does; reviewed frames with accepted boxes of it change only if you say so when asked. The class keeps its place and YOLO id. The auto-label defaults follow the classes the enabled models detect (Config page).
