Review

How review works

Frames collected from your cameras (Dataset page), one at a time, most uncertain first. Decide every box: accept the real objects, reject the false ones (kept as hard negatives), restore a wrongly suppressed box, draw what the model missed. They stay on this machine in {{ dir }}. Format: docs/DATASET.md. After an auto-label run, boxes marked auto: accept are accepted on save and auto: review ones (marked ?) ask first; frames with only accept boxes can be accepted in bulk. Press ? for the keys.

Labelling rules:

  • A tight box around the visible part of the object.
  • Parked cars are cars: an object left unlabelled teaches the model it is background.
  • A cyclist is a person box plus a bicycle box.
  • A person inside a vehicle only if clearly visible.
  • An object cut by the frame edge only if you can still recognise it.
  • Dark frames: look at them brightened (b) before deciding. A real object you still cannot name for sure is unsure (d): kept, left out of YOLO training, ignored by the benchmark set. Reject what is not an object at all.
  • Why a box was wrong is optional: after r, Shift+1-9 (insect / web, IR glare, reflection, ...) marks it for hard-negative mining.
  • Before saving, look over the whole frame for objects the model missed: they are the commonest label error.

    Auto-label these frames

    Proposes boxes for the frames the filters above select: they appear here as pending auto boxes. The labelers (MM-Grounding-DINO + RF-DETR L, checked by Qwen3-VL and SigLIP 2; NVIDIA GPU or Apple silicon) mark each box accept or review. A model (any detector from your config, a model file or a downloadable one) runs on any device, CPU included (RF-DETR L on CPU takes about 1 s per frame); its boxes are review unless you pre-accept them above a score. Frames the filters leave open default to the unreviewed ones in model mode. Runs on the Training page's queue, where the progress and a self-training check are.

    Export reviewed frames

    Writes YOLO (images/, labels/, data.yaml), COCO (annotations/), X-AnyLabeling (xanylabeling/) and a benchmark set (benchmark/, run it with benchmark --dataset dir:<folder>/benchmark).     Import from X-AnyLabeling

    Reads the .json files of an exported xanylabeling folder after you edited them in X-AnyLabeling. A file counts once its image is checked there; its rectangles become the frame's boxes (boxes you deleted are kept as rejected).

    Classes applies now
