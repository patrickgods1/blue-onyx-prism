    Export reviewed frames

    Writes YOLO (images/, labels/, data.yaml), COCO (annotations/), X-AnyLabeling (xanylabeling/) and a benchmark set (benchmark/, run it with benchmark --dataset dir:<folder>/benchmark). The split holds out whole cameras or days.

    Import from X-AnyLabeling

    Reads the .json files of an exported xanylabeling folder after you edited them in X-AnyLabeling. A file counts once its image is checked there; its rectangles become the frame's boxes (boxes you deleted are kept as rejected).

    Classes applies now

    The class list of this page and of the exports (collect.classes); YOLO class ids follow this order, so append rather than reorder once you exported.
