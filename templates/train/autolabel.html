Frames the model trained on are left out; validation and held-out frames stay in. Status and the frame source are ignored, threshold 0.3 means 0.5, limit 200 means every frame. Run it once per model. Which frames

Overlaps or duplicates: the Review tab's overlapping boxes; frames whose overlaps a reviewer already checked stay out. Custom: status, scene, camera, class and other filters.

key=value pairs, comma-separated: bucket, import (an import id, or any), source (queue, all; default all here), and any key above (scene day, night, ir; camera; label; status unreviewed, reviewed, skipped, any; auto review, accept, nothing, none, overlaps, both (a pending box found by 2+ labelers), dismissed (frames with hidden low-score boxes); again=1; limit).
