Checked models are compiled and served; the default model answers /v1/vision/detection. Saving applies at once.

How this works

Each model can run on its own device (OpenVINO and ONNX Runtime models run side by side; one ONNX Runtime flavor per process) and have its own confidence threshold per device: the Threshold field is for the device chosen in the Device column (choosing another device shows its value, or fills in the benchmark's best for it: Save keeps it), empty = the model's default (under Confidence per device), else the global {{ global_threshold }}; the Benchmark measures which device and threshold suit each model best. Running is what the loaded worker uses now. Thresholds apply without a reload, other changes reload only that model; a restart needed badge means the saved config differs from what runs and needs a server restart. Night model names another model that answers this model's night / IR frames (dark or monochrome; the frame is decoded once and handed over; while that model is not loaded the frame runs here); night models do not chain. Other per-model settings (classes, object filter, lazy, GPU precision) are in the Models JSON below, which stays in sync with this card.

How downloads and exports work

With auto download on (Server tab), whatever the config needs is fetched at startup. A new runtime is used after a restart (automatic when a model waits for it). Some models are not downloadable as ONNX (licenses per recipe under About exports): use Export in the exported models section, or export by hand with scripts/export_model.py --out-dir "{{ models_dir }}" (see the README); other model files show up under Local models. The NVIDIA CUDA/cuDNN libraries (for ort:cuda without a CUDA 12 / cuDNN 9 install) are covered by NVIDIA's license.
